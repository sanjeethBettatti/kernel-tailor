# Decisions

Architecture decision records (ADRs) capture durable choices that would be
expensive to rediscover. Chat history is not a decision record.

## Rules

- One decision per ADR, numbered `ADR-NNNN`.
- Status is `proposed`, `accepted`, `rejected`, or `superseded by ADR-NNNN`.
- An accepted ADR is not edited to change its meaning; supersede it instead.
- Record the alternatives that were seriously considered, not a strawman.
- Link the code, contract, or task that implements the decision.
