# Code of Conduct

This project welcomes contributions from people with any level of kernel, Rust,
or Linux experience. We want the learning curve to be the only hard part.

## Expected behavior

- Be respectful and specific when discussing code and hardware.
- Assume good faith, especially with newcomers.
- Give actionable review feedback and explain the "why".
- Respect privacy: do not ask for or publish serial numbers, MAC addresses, disk
  UUIDs, hostnames, or other identifying machine data.
- Credit other people's work and ideas.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Publishing private information without consent.
- Dismissing questions because they seem basic.
- Deliberately misleading hardware reports or benchmark results.
- Pressuring anyone to run privileged or boot-changing commands on their machine.

## Scope

This code applies to issues, pull requests, discussions, chat, and any project
space. It also applies when representing the project elsewhere.

## Enforcement

Maintainers may edit or remove comments, close threads, or temporarily or
permanently ban participants for behavior that violates this code. Enforcement
decisions are made in good faith and focus on protecting contributors.

Report concerns privately to the repository maintainer through GitHub. Do not
open a public issue containing personal details. Reports will be handled as
confidentially as practical.
